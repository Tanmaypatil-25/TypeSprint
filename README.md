# TypeSprint

A minimal typing speed test built with HTML, CSS, and vanilla JavaScript. TypeSprint provides a distraction-free environment to practice typing and track speed and accuracy in real time.

## Features

- Real-time WPM and accuracy tracking
- 15, 30, and 60-second typing tests
- Character-level feedback for correct and incorrect inputs
- Randomized typing passages
- Results summary with speed, accuracy, and mistakes
- Personal best tracking using localStorage
- Responsive, minimal dark interface

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Tanmaypatil-25/TypeSprint.git
```

Navigate to the project directory:

```bash
cd TypeSprint
```

Open `index.html` in your browser. No installation or additional dependencies are required.

## Usage

Select a test duration and start typing the displayed passage. The timer begins automatically with your first keystroke.

Your speed and accuracy are calculated as you type. Once the timer ends, you can review your results and start another test.
